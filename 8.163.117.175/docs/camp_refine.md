# 阵营精炼（我的装备页"精炼等级"四格）

参考（已存页 011_my_equip、206_a2_equip、pages_dump_acc2_r3.md）：我的装备页套装行下方显示
`精炼等级：[白][白][白][白]`，账号2 为 `[粉][粉][粉][粉]` 等；观察到的颜色有 白/绿/蓝/紫/粉，四格各自独立。
用户确认：这是阵营功能，加属性，与装备颜色/品质无关。

实现：AchieveDb::campRefine（player_kv camp_ref1..4，档位 0..4 = 白绿蓝紫粉），在阵营页 760 升级。
**以下均为估计值，参考未抓到：**
- 每格属性：1=HP+500/档，2=攻击+200/档，3=防御+250/档，4=魔攻+150/档
- 升级消耗：阵营贡献值 100×下一档
- 加成计入 wj/ztt.php 的属性（与命石同处），因此计入状态页与战力

物品自身的[装备精炼]（魔珠+四石，refine_lv）效果参考未知：不再按每级+5% 计入 (+N)，物品详情也不再显示"精炼等级:N"（参考详情页无此行）。
