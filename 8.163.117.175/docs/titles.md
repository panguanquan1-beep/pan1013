# 称号物品（title_def / player_title）

来源：参考号状态页称号行（reference/pages/203_a2_status.html、913_r3_状态.html），旁证 810 页。

- 物品 id 9201–9232，名称〖称号〗，分类 其它，可交易（bind_type 0），物品颜色同称号颜色。
- 使用：effect_type='title'，effect_value=title_def.id。可升级称号每用一次 +1 级、加成叠加；其余只能用一次，再次使用提示「不能重复使用」且不扣物品。
- 显示：状态页（头衔行下）与他人页（国家行下），按 sort 排序，HTML = `[<font color=颜色>disp</font>]suffix`，颜色照抄参考。
- 加成计入 wj/ztt.php（生命/攻击/防御/魔攻），战力随之变化。
- **占位值**：所有称号 attr=hp、per_use=1000，参考未给出真实值，改 title_def.attr / per_use 即可。
- 参考笔误：`[[13级大富豪`（多一个 [）、`[18富豪]`（缺 级），统一为 `[N级大富豪]` / `[N级富豪]`。
