# 图片与任务标记：以后改动不许关掉

## 规则
1. 任务 NPC 名字前必须有任务标记。打开图片时显示 `fqxy/pic/ts/ts1.png`（感叹号：可接或进行中），或 `ts2.png`（问号：可交付）；关闭图片时显示文字 ！/？。
2. 标记统一在 `fqxy/map/MapRenderer.php::renderNpcs` 里输出，调用的是 `QuestNpcUi::markerAt()`（lib/QuestNpcUi.php）。它对所有任务 NPC 生效：quest_def 里的发布、交付、对话目标 NPC，以及 39 级转职 NPC（`Zhuanzhi39::markType`）。
3. 新增或重建地图、清理 rwmap/xsc*.php、改 MapRenderer 时，不得删除这段代码，也不得给它加开关关掉。地图和 NPC 图片（`$tpbl`、RefImg、pic/ts、img/ref）同样不得关闭。
4. 改完以后至少用新号进村长家看一眼：首次进入时村长前有感叹号，杀完螃蟹后变成问号。
