# 战斗页 / 战斗结束页（按参考服复刻）

参考服 西游踏凌霄 的原始页面在 `docs/战斗页参考/`（sid 已替换为 SID）：

| 文件 | 内容 |
|---|---|
| 01_战斗开始 | 进入战斗 |
| 02_战斗回合 | 普攻一回合 |
| 03_回合_吃药 | 战斗中用快捷吃药 |
| 04_胜利、05_胜利_双头海龙 | 胜利页 |
| 06_被打死 | 死亡（自然发生，没有故意送死） |
| 07_死亡后返回游戏_十字街头 | 死后点返回游戏 |
| 08_逃跑后直接回场景 | 逃跑 |
| 09_查看怪物 | 战斗中查看怪物 |
| 10_战斗开始_低血警告 | 低血量进入战斗 |

## 格式（本地已照做）

**战斗开始**（xy010.php）

- 低血量时先输出 `<font color="red">【警告】</font>你的血量过低！请注意回复血量！`
- 快捷 1|2|3
- 怪物名
- `HP:当前`
- `自己:`
- `生命(当前/上限)`、`内力(当前/上限)`
- 快捷 4|5|6
- 快捷7 `&nbsp;|&nbsp;查看&nbsp;|&nbsp;逃跑`
- 快捷(宠物)8|9
- `状态 | 物品 | 宠物`
- `聊天 | 快捷键设置`
- `==========` 提示语 `==========`

**回合**

- 顶部 `生命-0<br/>内力-0<br/>`
- `HP:剩余-本回合伤害`
- `怪物向玩家使用了普攻[npc]！`
- `生命(…) -受到伤害`、`内力(…) -技能耗蓝`

**其它规则**

- 怪物台词、「你对X使用了一招…」：参考服不显示，已去掉。
- 快捷按钮：
  - 不再带蓝色 font，带 accesskey 1–9。
  - 名字显示全名（去掉【】〖〗），例如「红烧狗肉」。
  - 空位显示「快捷」，8、9 空位显示「快捷(宠物)」。
- 战斗中吃药（xy248 → ini_pz07）：`使用红烧狗肉<br/>生命+420<br/>`，然后接战斗页。

**胜利**（xy350.php）

```
生命-0
经验+N
你赢了这场战斗
任务:xxx(1/1)
得到〖物品〗xN
[返回游戏](accesskey 0)
```

- 掉落行在任务进度之后。
- 去掉了「X被你打死了！！！」和[继续走]。

**死亡**（xy349.php）

```
生命-0
X向玩家使用了普攻[npc]！
你被X打死了
[返回游戏](accesskey 0)
```

- 满血满蓝，回到十字街头 (1,0)，不扣经验（参考服实录）。

**逃跑**：直接回场景，没有任何提示（链接到页面 2）。

**查看**（xy019.php）

- 依次显示：名字、等级:N级、体力:当前/上限、攻击、防御、魔攻、独立攻击:0、独立防御:0、自愈量：0。
- 元素显示为 `???`。
- 底部是 [返回战斗] 和 `==========`。

## 没能完全复刻 / 未知

- 参考服整页包在 `<p>` 里；本地沿用 xy.php 外层 div，没有 `<p>`（显示效果相同）。
- 链接用本地 `xy.php?uid=…&&cmd=…` 格式，不是 gCmd.do。
- 回合顶部的「生命-0 / 内力-0」含义未知（参考服始终是 -0），本地照写固定值。
- 低血警告阈值未知：实录 2273/11798（19%）出现，本地用低于 1/4。
- 参考服怪物回血时名字后有「[自愈]」；本地怪物没有自愈机制，不显示。自愈量固定显示 0。
- 怪物出手文字本地固定「使用了普攻[npc]」（参考服实录也只见过普攻）。
- 宠物出战时的显示格式参考服没有抓到，本地按同一风格写「宠物: / 名字 / 生命(…)」。
- 世界 BOSS 战斗页（xy130）只同步了快捷按钮格式，其余未改。
- 快捷(宠物) 8、9：参考服是宠物技能位；本地仍是普通快捷位，只是空位名字一致。
- 「状态/物品/宠物/聊天」从战斗页进去后返回的是游戏页，不会回战斗（参考服未验证）。

本地测试（PHP 5.6 + MySQL 5.6），测试号在海底莽林打鲨鱼精。以下页面都和参考格式一致：

- 开始页、回合页
- 查看页 → 返回战斗
- 逃跑 → 回到场景
- 被打死 → 返回游戏 → 回到十字街头
- 胜利页

吃药页只做了语法检查，没有实际点过。
