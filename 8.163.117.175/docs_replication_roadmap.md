# 复刻《西游踏凌霄》路线图

原则：参考版里有的功能就复刻，参考版里没有的就删除。每个系统都要做到两点：数据存进 MySQL 表，页面按参考版逐字排版。每一步单独提交 git，可回滚。用户只看成果，细节由开发自行决定。

## 已完成 · 阶段A：物品与装备
- **表结构**：item_def 已扩展；新增 item_attr、player_item（实例表）、player_item_gem、player_equip、player_stat_bonus。SQL 在 sql_schema/006、007，测试物品在 900（删除用 901）。
- **页面**：
  - 701 背包，702 详情，703 使用/穿上，704/705 丢弃，706/707 批量使用，708 上锁。
  - 709 我的装备（14 个部位），710 卸下，711 空部位穿戴，716–718 宝石卸下/镶嵌。
  - 712–715 是存根：挂出销售、装备精炼、挂牌列表、打孔。
- **兼容**：旧页面 26–37、81–83、330–333 已转到新页面。状态和战斗属性（wj/ztt.php）改为读 ItemDb::equipTotals。
- **顺带修复**：page_unlock 作用域 bug。之前所有用 page_lock 的页面都会多打印一句“服务器开小差了”，123 页也是这个原因。
- **遗留**：wp/data/equipment.php 和 zbxx.php 还被约 30 个旧页面引用，包括升星、强化、摆摊、宝宝等。这些页面会随下面的各个阶段一起删除或改写，最后一个引用去掉后，再删除 equipment.php、zb.ini 和 zbb.ini。

删除方式：页面改为存根“该功能已下线”，入口链接全部移除，代码移到 legacy_templates，**不删数据**。

## 改造顺序（每项都是“ini → DB + 参考排版”）
1. **B 阶段 · 物品补全**：挂牌寄售（替代摆摊）、打孔、装备精炼（精炼等级四格）、强化 +N、仓库页。
2. **C 阶段 · 角色**：状态页、技能、金丹、声望。玩家主数据从 zt.ini/yl.ini 迁到 player 表，银两用 DECIMAL(40,0)。
3. **D 阶段 · 地图 / NPC / 任务**：地图坐标、腾云符目的地菜单按参考版排版，任务表化。
4. **E 阶段 · 战斗**：ztt.ini 缓存改为 DB 加缓存，战斗公式集中到一个类。
5. **F 阶段 · 社交**：好友、伴侣、师徒、阵营、成就、命石；同时删除帮派、擂台、宝宝、邮件。
6. **G 阶段 · 商城 / 丫币赞助**：参考版有丫币，充值接口先做存根。

## PHP 8.3 升级时机
放在 **D 阶段结束、E 阶段开始之前**。

理由：
- 到那时物品、角色、地图都已经改成新代码（mysqli 预处理语句、无 bcmath 隐患），剩下没改的旧代码最少。
- 战斗是最复杂的模块，正好在 8.3 上直接重写。

做法：
- 新开 php83 容器并行运行，用同一套 curl 回归脚本对比两边输出。
- 结果一致后切换；旧容器保留一个版本周期，方便回退。
- 已知风险：each()、create_function、未定义下标警告（8.x 变成 Warning）、`{}` 字符串下标、mysql_* 函数。
